# MyChef AI

Personal Hebrew, right-to-left recipe PWA. Version 0.5.0.

## Current capabilities
- Local recipe book, manual editing, version history, backups, timers and cooking mode.
- Personal ingredient preferences and food-label nutrition entries are stored on this device only.
- Recipe nutrition estimates cover calories, protein, carbohydrates, fat and fiber. A small offline USDA catalog is included; users can also enter package-label values per 100 g. Unknown foods and unsupported units are shown as missing.
- Video files are previewed locally; only a user-selected still frame may be saved with a recipe. No image or video AI analysis is active.

## Install
Open the hosted HTTPS app in Safari on iPhone, then choose Share > Add to Home Screen. On Android, open it in Chrome and choose Install app / Add to Home screen.

Recipes, photos and preferences are stored locally in the browser and are not synchronized to this repository. Nutrition figures are estimates, not measurements or medical advice.

General nutrition data source: [USDA FoodData Central](https://fdc.nal.usda.gov/), public-domain data (CC0). The app uses a limited bundled subset and makes no nutrition API requests.
